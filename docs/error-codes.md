# 错误代码文档

本文档详细说明了系统中的错误类型和错误代码，以及它们的含义和解决方法。

## 错误类型

错误类型用于分类错误，帮助开发人员和用户理解错误的性质。

| 错误类型 | 描述 | 可重试 |
|---------|------|-------|
| `GENERAL` | 通用错误，不属于其他特定类型 | 否 |
| `VALIDATION` | 输入数据验证失败 | 否 |
| `DATABASE` | 数据库操作失败 | 是 |
| `AUTHENTICATION` | 认证失败，如登录失败、会话过期等 | 否 |
| `AUTHORIZATION` | 授权失败，如权限不足 | 否 |
| `NOT_FOUND` | 请求的资源不存在 | 否 |
| `ALREADY_EXISTS` | 资源已存在，如创建重复记录 | 否 |
| `BUSINESS_LOGIC` | 业务逻辑错误，如库存不足、订单已取消等 | 否 |
| `EXTERNAL_SERVICE` | 外部服务错误，如第三方 API 调用失败 | 是 |
| `SYSTEM` | 系统错误，如内部服务器错误 | 是 |

## 错误代码

错误代码是唯一标识符，用于精确定位错误。

| 错误代码 | 错误类型 | 描述 | 解决方法 |
|---------|---------|------|---------|
| `E0001` | `GENERAL` | 通用错误 | 查看错误消息获取更多信息，如果问题持续存在，请联系管理员 |
| `E0002` | `VALIDATION` | 输入数据验证失败 | 检查输入数据是否符合要求，修正后重试 |
| `E0003` | `DATABASE` | 数据库操作失败 | 稍后重试，如果问题持续存在，请联系管理员 |
| `E0004` | `AUTHENTICATION` | 认证失败 | 检查用户名和密码，或重新登录 |
| `E0005` | `AUTHORIZATION` | 授权失败 | 确认您有权执行此操作，如需更多权限，请联系管理员 |
| `E0006` | `NOT_FOUND` | 资源不存在 | 检查资源 ID 是否正确，或者资源可能已被删除 |
| `E0007` | `ALREADY_EXISTS` | 资源已存在 | 使用不同的标识符，或者检查是否需要更新现有资源 |
| `E0008` | `BUSINESS_LOGIC` | 业务逻辑错误 | 根据错误消息调整操作，确保符合业务规则 |
| `E0009` | `EXTERNAL_SERVICE` | 外部服务错误 | 稍后重试，如果问题持续存在，请联系管理员 |
| `E0010` | `SYSTEM` | 系统错误 | 稍后重试，如果问题持续存在，请联系管理员 |

## 常见错误及解决方法

### 验证错误 (E0002)

验证错误通常是由于输入数据不符合要求导致的。

**常见原因：**
- 必填字段为空
- 字段格式不正确（如邮箱、日期等）
- 字段长度超出限制
- 数值范围不符合要求

**解决方法：**
1. 检查错误消息，了解具体哪个字段有问题
2. 根据字段要求修正输入数据
3. 重新提交

### 数据库错误 (E0003)

数据库错误通常是由于数据库操作失败导致的。

**常见原因：**
- 数据库连接问题
- 数据库查询超时
- 数据库约束冲突
- 数据库服务器负载过高

**解决方法：**
1. 稍后重试操作
2. 如果问题持续存在，请联系管理员
3. 检查是否有数据库约束冲突，如唯一键冲突

### 认证错误 (E0004)

认证错误通常是由于用户身份验证失败导致的。

**常见原因：**
- 用户名或密码错误
- 会话过期
- 账户被锁定
- 多设备登录冲突

**解决方法：**
1. 检查用户名和密码
2. 重新登录
3. 如果账户被锁定，请联系管理员
4. 确认是否有其他设备登录了同一账户

### 授权错误 (E0005)

授权错误通常是由于用户没有执行某操作的权限导致的。

**常见原因：**
- 用户角色权限不足
- 操作需要更高级别的权限
- 资源所有者限制

**解决方法：**
1. 确认您的用户角色是否有权执行此操作
2. 如需更多权限，请联系管理员
3. 如果是资源所有者限制，请联系资源所有者

### 资源不存在错误 (E0006)

资源不存在错误通常是由于请求的资源不存在导致的。

**常见原因：**
- 资源 ID 不正确
- 资源已被删除
- 资源已过期

**解决方法：**
1. 检查资源 ID 是否正确
2. 确认资源是否已被删除
3. 如果资源已过期，请创建新资源

### 业务逻辑错误 (E0008)

业务逻辑错误通常是由于操作不符合业务规则导致的。

**常见原因：**
- 库存不足
- 订单已取消
- 状态转换不允许
- 数据关联约束

**解决方法：**
1. 根据错误消息调整操作
2. 确保操作符合业务规则
3. 如果不确定如何解决，请参考业务流程文档

## 错误监控

系统使用 Sentry 进行错误监控，自动捕获和报告错误。如果您遇到未在此文档中列出的错误，请将错误 ID（通常显示在错误消息中）提供给管理员，以便进一步调查。
