# 随手记ERP应用原型设计

这是一个类似随手记的ERP应用原型设计，使用HTML、Tailwind CSS和FontAwesome图标库实现。

## 项目结构

- `index.html` - 主入口文件，展示所有界面
- `login.html` - 登录界面
- `dashboard.html` - 主页/仪表盘
- `finance.html` - 财务管理
- `add-transaction.html` - 记账界面
- `inventory.html` - 库存管理
- `sales.html` - 销售管理
- `employees.html` - 员工管理
- `settings.html` - 系统设置

## 如何使用

1. 直接在浏览器中打开 `index.html` 文件
2. 所有界面将以iPhone 15 Pro尺寸的手机界面展示
3. 每个界面都包含iOS风格的状态栏和底部导航栏
4. 点击各个界面可以查看详细设计

## 设计特点

- 遵循iOS设计规范
- 使用真实感UI元素
- 响应式设计
- 模拟真实的手机界面
- 包含常见的ERP功能模块

## 功能模块

1. **登录/注册**
   - 用户名/密码登录
   - 第三方登录选项
   - 忘记密码功能

2. **主页/仪表盘**
   - 收支概览
   - 快捷功能入口
   - 最近交易记录
   - 库存预警

3. **财务管理**
   - 收支记录
   - 账户管理
   - 财务报表
   - 记账功能

4. **库存管理**
   - 库存概览
   - 产品管理
   - 库存预警
   - 库存分析

5. **销售管理**
   - 订单管理
   - 客户管理
   - 销售统计
   - POS功能

6. **员工管理**
   - 员工信息
   - 排班管理
   - 工资管理
   - 绩效评估

7. **系统设置**
   - 个人信息
   - 账户安全
   - 系统参数
   - 用户权限

## 技术栈

- HTML5
- Tailwind CSS
- FontAwesome 图标库
- 纯前端实现，无后端依赖

## 开发与扩展

这些原型设计可以直接用于实际开发，开发人员可以：

1. 将HTML结构转换为React/Vue组件
2. 添加JavaScript交互逻辑
3. 连接后端API实现数据交互
4. 根据需求调整UI细节

## 注意事项

- 原型中的数据均为模拟数据
- 界面设计遵循iOS设计规范，可根据Android平台需求进行调整
- 原型中的图片使用了在线占位图，实际开发中应替换为项目实际图片
