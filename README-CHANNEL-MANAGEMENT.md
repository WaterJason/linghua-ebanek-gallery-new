# 渠道管理模块使用说明

## 简介

渠道管理模块是聆花掐丝珐琅馆ERP系统的重要组成部分，用于管理渠道商的基本信息、专属供货价格、渠道库存、押金、配货、销售和结算等功能。本模块与现有的库存管理模块紧密集成，实现了渠道库存与现有库存的实时同步。

## 功能概述

1. **渠道商管理**：管理渠道商的基本信息，包括名称、编码、联系人、联系方式、地址、银行账户等。
2. **渠道价格管理**：为每个渠道商设置专属的供货价格。
3. **渠道库存管理**：管理每个渠道商的商品库存，包括库存数量、最小库存等。
4. **渠道押金管理**：管理渠道商的押金收取、退还和抵扣。
5. **渠道配货管理**：管理向渠道商配货的记录，包括配货数量、日期和状态等。
6. **渠道销售管理**：管理渠道商的销售记录，支持从Excel导入销售数据。
7. **渠道结算管理**：管理渠道商的结算单，包括结算周期、结算金额、付款状态等。

## 使用指南

### 渠道商管理

1. 点击"渠道管理"菜单，进入渠道管理页面。
2. 在"渠道商管理"标签页中，可以查看所有渠道商的列表。
3. 点击"添加渠道商"按钮，填写渠道商信息，点击"创建"按钮保存。
4. 点击渠道商列表中的"编辑"按钮，可以修改渠道商信息。
5. 点击渠道商列表中的"删除"按钮，可以删除渠道商（前提是没有关联数据）。

### 渠道价格管理

1. 在"渠道价格"标签页中，可以查看所有渠道商的价格设置。
2. 点击"添加价格"按钮，选择渠道商和产品，设置价格，点击"创建"按钮保存。
3. 点击价格列表中的"编辑"按钮，可以修改价格。
4. 点击价格列表中的"删除"按钮，可以删除价格设置。

### 渠道库存管理

1. 在"渠道库存"标签页中，可以查看所有渠道商的库存情况。
2. 点击"添加库存"按钮，选择渠道商和产品，设置库存数量，点击"创建"按钮保存。
3. 点击库存列表中的"编辑"按钮，可以修改库存数量。
4. 点击库存列表中的"删除"按钮，可以删除库存记录（前提是没有关联数据）。

### 渠道押金管理

1. 在"押金管理"标签页中，可以查看所有渠道商的押金记录。
2. 点击"添加押金记录"按钮，选择渠道商，设置押金类型（收取、退还、抵扣）、金额和日期，点击"创建"按钮保存。
3. 点击押金列表中的"删除"按钮，可以删除押金记录。

### 渠道配货管理

1. 在"渠道配货"标签页中，可以查看所有渠道商的配货记录。
2. 点击"新增配货"按钮，选择渠道商和产品，设置配货数量和日期，点击"创建"按钮保存。
3. 点击配货列表中的"标记为已发货"按钮，可以将配货状态更新为已发货。
4. 点击配货列表中的"标记为已收货"按钮，可以将配货状态更新为已收货。

### 渠道销售管理

1. 在"渠道销售"标签页中，可以查看所有渠道商的销售记录。
2. 点击"导入销售数据"按钮，选择渠道商，上传Excel文件，设置销售日期，点击"导入"按钮保存。
3. 点击销售列表中的"确认"按钮，可以将销售状态更新为已确认。
4. 点击销售记录可以查看详细信息。

### 渠道结算管理

1. 在"结算管理"标签页中，可以查看所有渠道商的结算单。
2. 点击"创建结算单"按钮，选择渠道商，设置结算周期，点击"创建结算单"按钮保存。
3. 点击结算单列表中的"确认"按钮，可以将结算单状态更新为已确认。
4. 点击结算单列表中的"添加发票"按钮，可以添加发票记录。
5. 点击结算单列表中的"标记付款"按钮，可以将结算单状态更新为已付款。
6. 点击结算单可以查看详细信息。

## 数据导入导出

### 销售数据导入

1. 在"渠道销售"标签页中，点击"导入销售数据"按钮。
2. 选择渠道商，上传Excel文件，设置销售日期。
3. 系统会自动解析Excel文件中的销售数据，并显示预览。
4. 确认无误后，点击"导入"按钮保存。

### 结算单导出

1. 在"结算管理"标签页中，点击结算单查看详细信息。
2. 在结算单详情页面，可以导出结算单为PDF或Excel格式。

## 注意事项

1. 渠道库存与现有库存是实时同步的，当向渠道商配货时，现有库存会减少，渠道库存会增加。
2. 当渠道商销售商品时，渠道库存会减少，但现有库存不会增加。
3. 结算单只能包含已确认的销售记录，未确认的销售记录不会被结算。
4. 结算单创建后，包含在结算单中的销售记录状态会更新为已结算，不能再次被结算。
5. 押金余额不足时，无法进行退还或抵扣操作。

## 数据库迁移

在使用渠道管理模块之前，需要先执行数据库迁移脚本。迁移脚本位于 `prisma/migrations/channel_management_migration.sql`，可以通过以下命令执行：

```bash
# 使用 Prisma CLI 执行迁移
npx prisma migrate dev --name add_channel_management

# 或者直接在数据库中执行 SQL 脚本
psql -U <用户名> -d <数据库名> -f prisma/migrations/channel_management_migration.sql
```
