# 聆华ERP移动端PWA应用

## 项目概述

聆华ERP移动端是一个基于渐进式Web应用(PWA)技术开发的移动端应用，旨在为用户提供随时随地访问ERP系统的能力。该应用采用现代化的前端技术栈，具有离线工作能力、响应式设计和接近原生应用的用户体验。

## 技术栈

- **前端框架**: Next.js 15.x
- **UI组件库**: 基于Tailwind CSS的自定义组件
- **PWA支持**: next-pwa
- **离线存储**: IndexedDB (通过idb库)
- **状态管理**: React Hooks + Context API
- **数据获取**: SWR + Server Actions
- **数据库**: PostgreSQL (通过Prisma ORM)

## 功能特性

### 1. PWA基础功能

- **离线工作**: 支持在无网络环境下继续工作
- **安装到主屏幕**: 提供类似原生应用的体验
- **后台同步**: 网络恢复后自动同步离线操作
- **推送通知**: 接收重要事件的实时通知

### 2. 业务模块

- **仪表盘**: 提供业务概览和快捷操作
- **财务管理**: 记账、账户管理、财务报表
- **库存管理**: 库存查询、库存预警、库存分析
- **销售管理**: 订单管理、客户管理、POS销售、销售统计
- **员工管理**: 员工信息、排班管理、工资管理、绩效评估
- **系统设置**: 个人设置、应用设置、系统管理

## PWA功能说明

### 1. 离线功能

应用使用Service Worker和IndexedDB实现离线功能：

- **静态资源缓存**: 缓存HTML、CSS、JavaScript等静态资源
- **API响应缓存**: 根据不同API采用不同的缓存策略
- **离线数据存储**: 使用IndexedDB存储关键业务数据
- **离线操作记录**: 记录离线状态下的用户操作，等待网络恢复后同步

### 2. 数据同步

应用实现了强大的数据同步机制：

- **自动同步**: 网络恢复后自动同步离线数据
- **手动同步**: 用户可以手动触发同步操作
- **冲突解决**: 智能处理同步过程中的数据冲突
- **同步状态显示**: 清晰显示同步状态和进度

### 3. 安装体验

应用提供了原生应用般的安装体验：

- **安装提示**: 智能提示用户将应用添加到主屏幕
- **启动屏幕**: 自定义启动屏幕，提升品牌体验
- **全屏模式**: 隐藏浏览器UI，提供沉浸式体验

### 4. 性能优化

应用采用多种技术优化性能：

- **代码分割**: 按需加载代码，减少初始加载时间
- **资源预加载**: 预加载关键资源，提升用户体验
- **图像优化**: 使用现代图像格式和懒加载技术
- **性能监控**: 实时监控应用性能指标

## 最佳实践

### 1. 离线优先设计

- 默认假设用户处于离线状态
- 优先使用本地数据
- 在后台同步数据，不阻塞用户操作

### 2. 渐进增强

- 基本功能在所有浏览器中可用
- 高级功能在支持的浏览器中渐进增强
- 优雅降级，确保核心功能始终可用

### 3. 响应式设计

- 适应不同屏幕尺寸和方向
- 触控友好的界面元素
- 针对移动设备优化的交互
